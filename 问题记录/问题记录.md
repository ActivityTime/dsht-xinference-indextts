# Xinference + IndexTTS-2.5 落地问题记录

> 时间：2026-10-24
> 范围：删除 VoiceStudio → 安装 Xinference 4.0.1 → 修复 torch → 换装 CUDA torch → 服务启动排障 → 准备 IndexTTS-2.5 加载

---

## 1. torch 导入报 `PermissionError: [WinError 5] 拒绝访问`

**现象**：新 venv 里 `import torch` 加载 `torch_python.dll` 被拒。

**根因**：`C:\Windows\System32` 整套 MSVC / OpenMP / Concurrency 运行库 **ACL 损坏**（CONCRT140、MSVCP140_1、MSVCP140_2、MSVCP140_atomic_wait、MSVCP140_codecvt_ids、VCOMP140 等连读取都被拒，icacls 也读不出 ACL）。VCOMP140 本身正常（早期 VoiceStudio 工单已修过），真凶是其余 DLL。

**修复**：提权执行 `takeown + icacls reset + grant` 逐个修复。

**插曲**：两次提权"白跑"——修复脚本第 19 行引号笔误 `"[== $d =="]`（少收尾 `]`），整脚本解析失败。修正后提权执行成功。

## 2. CUDA torch 换装（CPU 版不能用）

**现象**：默认 `pip install xinference` 装的是 **CPU 版 torch**（`cuda=False`），RTX 3080 用不了。

**根因**：cu128 索引最高只有 **torch 2.11.0**（CPU 版 2.14.1 是另一条线，无 cu128 2.14.1）。

**修复**：
- 官方源 `download.pytorch.org/whl/cu128/` 的 2.75GB 大轮经 **pip 下载停滞**（10 分钟无增长）→ 改用 **curl 直连**（实测 14-15MB/s，~3 分钟）。
- **阿里云 `mirrors.aliyun.com/pytorch-wheels/cu128/` 无 Windows cp313 win_amd64 轮**（`/torch/` 404，目录里也没有），不可用。
- **wheel 文件名被截短**（如 `...-cp313-win`）导致 pip 报 `Invalid wheel filename (wrong number of parts)` → 改回标准全名（`cp313-cp313-win_amd64`）后 `pip install --force-reinstall --no-deps` 本地安装成功。
- 最终：`torch 2.11.0+cu128 / torchaudio 2.11.0+cu128 / torchvision 0.26.0+cu128`，`cuda_available=True`，RTX 3080 (8,6)=sm_86 ✓。

## 3. Xinference 服务起不来：`RuntimeError: Cluster is not available after multiple attempts`

**现象**：`xinference-local` 启动 ~10s/66s 后退出，health 连不上。

**根因（三层，全部要改）**：
1. **`--host 0.0.0.0` 导致内部 health_check 连不上子进程**：xinference 的 supervisor/worker 绑定 `0.0.0.0:随机端口`，父进程 `health_check` 用字面 `0.0.0.0:端口` 去 `xo.actor_ref` 连接（Windows 上连 0.0.0.0 失败）→ **改用 `127.0.0.1`**（本地自用足够）。
2. **子进程就绪等待默认 10s 太短**：xinference-local 会拉起 supervisor/worker 子进程，首次启动要 **~50-90s**（导入 torch + CUDA 初始化 + GPU orphan 扫描 20+ 进程）才发 READY；父进程超时退出时把 daemon 子进程带走。→ 设 **`XINFERENCE_HEALTH_CHECK_TIMEOUT=180`**（实测 ~51s 就绪）。
3. 调大后仍失败（连 0.0.0.0 的问题叠加）——把 127.0.0.1 + 180s 一起改后通过。

## 4. 4.x 新增鉴权：`/v1/models` 返回 401

**现象**：首次启动日志提示需 `POST /v1/admin/setup` 建管理员账号，`/v1/models` 401。

**修复**：设 **`XINFERENCE_AUTH_ADVANCED=0`** 完全关闭鉴权（本地直连免 token）。验证后 `/v1/models` 200。

## 5. `/health` 在 4.0.1 返回 404

**现象**：用 `/health` 探测总是连不上。

**修复**：4.x 用 **`/status`**（200）探测。

## 6. `xinference launch` CLI 无法传 `use_bf16`

**现象/原因**：`xinference launch --help` 无 `use_bf16`/`--model-config` 选项，无法让 IndexTTS-2.5 以 bf16 加载。

**修复**：用 **Python 客户端** `RESTfulClient.launch_model(model_config={"use_bf16": True})`（`**kwargs` 原样并入 payload）。已封装 `launch_indextts.py`。

## 7. IndexTTS-2.5 权重精度说明

- **下载**：官方全精度 `IndexTeam/IndexTTS-2.5`（HF，约 6GB）。**无量化版本**（管线无 int8/int4/GGUF）。
- **运行时**：默认 fp32（`use_bf16=False`）；设 `use_bf16=True` 时**加载时 cast 成 bf16**（内存优化，非真量化）。RTX 3080 10GB 建议 bf16。

## 8. 本机环境特殊性（易踩坑）

- `APPDATA`/`LOCALAPPDATA`/`USERPROFILE` 均解析到 **K:\Users\ACTIM.DESKTOP-BPAEDTM**（非 C 盘）。
- `python` 命令第一个解析到**豆包沙箱运行时 Python**（不可用于正式安装）；真实系统 Python 在 `K:\Users\ACTIM.DESKTOP-BPAEDTM\AppData\Local\Programs\Python\Python313\python.exe`（3.13.16）。
- pip 默认走**华为云镜像** `https://mirrors.huaweicloud.com/repository/pypi/simple/`。
- `$HOME` 是 PowerShell 保留变量，脚本里别用 `$home` 存用户目录。
