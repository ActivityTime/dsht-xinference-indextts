# 外部引用与配置（Xinference · 配置化改造 2026-10-24）

> 规则：**内部路径一律相对 `config.ps1` 定位，禁止绝对路径；外部引用环境在此明文列出。**

## 一、配置化规则

- 中央配置：`K:\SomeApps\Xinference\config.ps1`（必须与 `start_xinference_indextts.ps1` 同目录，被 dot-source）。
- **内部路径**（venv / .xinference / launch / test 脚本）由 `config.ps1` 基于自身所在目录**相对计算**，不写任何绝对路径。
- **外部引用**在 `config.ps1` 的 `$Script:ExternalDeps` 明文列出（下表）。
- 环境变量（`XINFERENCE_HOME` / `HF_*` / `XINFERENCE_ENDPOINT` / `MODEL_NAME` 等）由 `config.ps1` 统一注入，各脚本只读取不硬编码。

## 二、内部自包含（全部在 K:\SomeApps\Xinference 内）

| 项 | 位置 | 说明 |
|---|---|---|
| 代码/环境 | `venv` | Python 3.13 + Xinference + torch（prefix 指向自身） |
| 模型/数据/日志 | `.xinference`（17.9GB） | cache + huggingface + model + virtualenv + logs + 各 db |
| 启动 | `start_xinference_indextts.ps1` / `.bat` | 载入 config，相对定位 |

| 合成 | `tts_test.py` | 读环境变量，无硬编码 |
| 配置 | `config.ps1` | 中央配置（本文件） |

## 四、唯一允许的绝对路径

**User 级环境变量 `XINFERENCE_HOME = K:\SomeApps\Xinference\.xinference`** 是唯一允许的绝对路径（Xinference 规范要求，指向数据根，作为脱离脚本独立启动时的兜底）。脚本每次启动都用 `config.ps1` 相对定位重新注入，保证一致。

## 五、脚本改造记录（2026-10-24）

- **新增 `config.ps1`**：中央配置（相对定位 + 环境变量注入 + 外部依赖明文）。
- `start_xinference_indextts.ps1`：删除 `$venvDir`/`XINFERENCE_HOME` 硬编码绝对路径 → 改为 dot-source `config.ps1`，日志/launch 路径相对定位。
- `tts_test.py`：端点、模型名从环境变量读取（`XINFERENCE_ENDPOINT` / `MODEL_NAME`）。

- `start_xinference_indextts.bat`：原本即用 `%~dp0` 相对定位，未改。

## 六、整体搬文件夹步骤

1. 移动整个 `K:\SomeApps\Xinference` 到新位置（venv 与 `.xinference` 相对结构自包含，可直接搬）。
2. 改 User 级 `XINFERENCE_HOME` 指向新位置下的 `.xinference`（或用脚本启动则自动重算，可不动）。
3. **无需改任何脚本**（内部路径全部相对 `config.ps1` 自动适应）。
4. 前提：目标机必须存在 ① 同版基础 Python 3.13；② NVIDIA 驱动（sm_86）；③ MSVC 运行库——否则 venv 无法启动。
