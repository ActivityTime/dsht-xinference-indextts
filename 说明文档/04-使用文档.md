## 一、它能做什么

一句话：**给你任意一个动漫角色，给一段干净参考音频，就能让 Ta 用 IndexTTS-2.5 说中日英（还可西/阿）台词，且情绪可定量控制，全部本地。**

- 零样本克隆：参考音频即音色，免训练
- 免逐字稿：只传参考音频 + 文本，不要参考文字转录
- 情绪控制：8 维向量 / 情绪参考音频 / 文本描述，音色-情绪解耦
- 本地：无云端、无 API 费用

脚本自动完成：

看到 `OK model_uid=IndexTTS-2.5`（日志 `ModelActor(IndexTTS-2.5-rep0) loaded`）即就绪。权重已缓存，之后重拉约 2–3 分钟。

### 方式四：curl（PowerShell / bash / cmd 三版）

> 示例打 **9998 适配层**（multipart 与 JSON 等价）；若要打 9997 直连（无适配层），换端口即可但必须带 prompt_speech 文件。

> ⚠️ **关键**：kwargs 的 JSON **必须写文件后用 `-F "kwargs=<文件"` 传入**——命令行内联 JSON 会被 PowerShell 剥掉双引号，服务端 JSON 解析失败直接 **HTTP 500**（实测确认）。

**PowerShell 版（本机实测 HTTP 200）**：

```powershell
# 1) kwargs 写文件（改语言/情绪就改这里，UTF-8）
'{"language":"ZH"}' | Set-Content -Encoding utf8 <部署根>\logs\kwargs.json

# 2) 合成（PowerShell 反引号续行；-o 输出 wav，-w 打印状态码）
curl.exe -s -X POST http://127.0.0.1:9998/v1/audio/speech `
  -F "model=IndexTTS-2.5" `
  -F "input=你好，这是一次curl合成测试。" `
  -F "voice=default" `
  -F "response_format=wav" `
  -F "stream=false" `
  -F "speed=1.0" `
  -F "kwargs=<<部署根>\logs\kwargs.json" `
  -F "prompt_speech=@I:\SomeResources\VoiceClonePrompt-ForOmniVoice\prompt\arknights\zh\临光\clips\zh_临光_001_calm_日常交谈.wav;type=audio/wav" `
  -o out.wav -w "HTTP %{http_code}"
```

带情绪向量（kwargs 文件内容）：

```powershell
'{"language":"ZH","emo_vector":[0,1,0,0,0,0,0,0]}' |
  Set-Content -Encoding utf8 <部署根>\logs\kwargs.json
# 然后重跑上面的 curl 命令即可
```

要点：
- `prompt_speech` 用 `@绝对路径;type=audio/wav` 上传参考音频（音色来源）
- `-F "kwargs=<文件路径"`：`<` 表示从文件读取表单值（绕开 PowerShell 引号处理）
- 其他字段（`input` 等）命令行直接传即可，实测中文无问题

**bash 版（Git Bash，本机实测 HTTP 200）**：

> ⚠️ 两个实测要点：①**用系统 curl**（`/c/Windows/System32/curl.exe`）——Git 自带 `/ucrt64/bin/curl`（Debug 版）的 `-F` multipart 发送不兼容，合成直接 **HTTP 500 "Stream consumed"**；②**`prompt_speech` 的 `@` 后必须用 Windows 反斜杠路径**——MSYS 不转换 `-F` 值内部的路径，写 `/i/...` 会被原样传给 curl → 读文件失败 exit 26。

```bash
#!/bin/bash
# 存为 .sh（UTF-8 编码），Git Bash 里运行
CURL="/c/Windows/System32/curl.exe"

"$CURL" -s -X POST http://127.0.0.1:9998/v1/audio/speech \
  -F "model=IndexTTS-2.5" \
  -F "input=你好，这是一次curl合成测试。" \
  -F "voice=default" \
  -F "response_format=wav" \
  -F "stream=false" \
  -F "speed=1.0" \
  -F 'kwargs={"language":"ZH"}' \
  -F "prompt_speech=@I:\SomeResources\VoiceClonePrompt-ForOmniVoice\prompt\arknights\zh\临光\clips\zh_临光_001_calm_日常交谈.wav;type=audio/wav" \
  -o /k/SomeApps/Xinference/logs/out.wav \
  -w "HTTP %{http_code}"
```

要点：
- kwargs 单引号内联（bash 单引号是字面量，JSON 双引号完整保留，无 PowerShell/cmd 的剥引号问题）
- `@` 后写 Windows 反斜杠路径（bash 双引号内 `\S` 等原样保留；中文 UTF-8 正常）
- 独立路径参数（如 `-o /k/...`）会被 MSYS 自动转换，可用正斜杠

cmd 直接跑 curl 有三个实测坑：①`-w "HTTP %{http_code}"` 的 `%{http_code}` 被 cmd 当变量展开吃掉（输出变 `HTTP {http_code}`）；②`-F "kwargs=<文件"` 引号内的 `<` 仍被 cmd 当输入重定向，请求直接失败；③kwargs 内联 JSON 的引号被 cmd 拆分丢失 → HTTP 500。

## 六、IndexTTS-2.5 配置参数全表（Xinference）

### A. 加载配置（`launch`，`model_config`）

| 参数 | 说明 |
|---|---|
| `use_bf16=True` | bf16 加载省显存（官方对 GPU 强烈建议） |
| `use_qwen_emo=True` | 启用文本情绪需另挂 QwenEmotion（更占显存） |
| `small_models_dir` | 离线模式：指定小模型目录（w2v-bert / campplus / bigvgan / MaskGCT） |
| `model_uid` / `download_hub` / `model_engine` | 运行标识 / 权重源(hf|modelscope) / 引擎(默认PyTorch) |

### B. 推理参数（`/v1/audio/speech`）

**标准字段**：`model` `input` `voice` `response_format` `stream` `speed`（0.5–2.0，>1 加快）

**kwargs（直通 IndexTTS）**：

| 参数 | 说明 |
|---|---|
| `prompt_speech` | 参考音频（文件字段），音色克隆**必传**，免逐字稿 |
| `language` | `ZH/EN/JA/ES/AR`（实测 `lang` 也直通） |
| `duration_factor` | 0.5–2.0，>1 **放慢**；与 `speed` 二选一 |
| `emo_audio_prompt` + `emo_alpha` | 情绪参考音频；`emo_alpha` 0.0–1.0（默认 1.0） |
| `emo_vector` | 8 维 `[快乐,愤怒,悲伤,恐惧,厌恶,忧郁,惊讶,平静]` |
| `use_emo_text=True` + `emo_text` | 文本情绪描述自动转向量；建议 `emo_alpha≈0.6` |
| `use_random` | `True` 随机情绪（默认 `False`） |
| 发音控制 | `<word\|reading>`，如 `他在银<行\|XING2>里` |

### C. 服务环境变量

`XINFERENCE_HEALTH_CHECK_TIMEOUT=180` · `XINFERENCE_AUTH_ADVANCED=0` · `HF_ENDPOINT=https://hf-mirror.com` · `HF_HUB_DISABLE_XET=1` · `XINFERENCE_ENDPOINT=http://127.0.0.1:9997`

### 易混点
- `speed`（OpenAI，>1 加快）vs `duration_factor`（上游，>1 放慢）——别混用
- 三种情绪方式**三选一**：`emo_audio_prompt`（音频）/ `emo_vector`（向量）/ `emo_text`（文本）
- `use_emo_text` 需 `use_qwen_emo=True`（加载时开）；`emo_vector` 最省资源
- `prompt_speech` 必传，无默认音色

## 七、情绪控制实操建议

| 目的 | 推荐方式 |
|---|---|
| 日常固定情绪 | `emo_vector`（最省，不需 QwenEmotion） |
| 一句戏份要强烈情绪 | `emo_audio_prompt`（另给一段情绪参考音频）+ `emo_alpha≈0.9` |
| 想用自然语言描述 | `emo_text` + `use_emo_text=True`（需加载 QwenEmotion，`emo_alpha≈0.6`） |
| 复现参考音频语气 | 参考音频本身自带"表演风格"——挑语气贴合的片段最省事 |

> ⚠️ `emo_vector` 某维拉太高会偏离本人音色，关键台词从中等起步、多生成挑最好的。

## 八、参考音频怎么挑

见 `02-参考音频库清单.md`。要点：
- 参考音频库 `I:\SomeResources\VoiceClonePrompt-ForOmniVoice\prompt`，约战日语 **1047 段**最全
- 命名 `语种_角色_编号_情绪_场景.wav` → **按文件名情绪/场景标签挑语气贴合的**
- 取 3–10s 干净人声，别用混响/多人/长静音段

### 8.1 控制台里怎么把参考音频用起来

控制台 →「参考音频库」页，每个条目旁四个按钮：

| 按钮 | 得到什么 | 用在哪 |
|---|---|---|
| **复制名** | `默认音色库\|_ab_indexTTS/clips/甘雨/zh_Ganyu_0003_平静_疑问询问.wav` | 贴进控制台的 voice / 引导音频 / 情绪映射**配置框** |
| **复制音色指令** | `#[音色选择][默认音色库/_ab_indexTTS/clips/甘雨/zh_Ganyu_0003_平静_疑问询问.wav]` | 贴进**请求正文**（适配层 / DSHT 台词）→ 该音频作为音色 |
| **复制情感指令** | `#[情感控制][引导音频][默认音色库/…]` | 贴进**请求正文** → 该音频作为情感参考 |
| **用作参考** | — | 直接回填合成页的参考音频 |

复制成功后按钮会短暂显示「✓ 已复制」，同时右下角有 toast。

> ⚠️ 引用里**用库名而不是序号**。序号是库源在 `library.json` 里的排列位置，库源一增删/重排，历史引用全部错位（音色静默变别的文件）。详见 `05-外部引用与配置.md` 第六节。

### 8.2 内联指令（写在正文里，发送前自动剔除、不会朗读）

可写在 **input / instructions / voice 任一字段**；同一类出现多次时**首个生效**；不同类可同时使用，按 **适配模式 → 情感控制 → 音色选择 → 参数** 顺序应用。

| 指令 | 作用 |
|---|---|
| `#[适配模式][模式名]` | 最高级覆盖适配模式。模式名：文字情感 / 引导音频 / 切换音色 / 情绪向量 / 情绪映射（亦接受 `text_emotion` / `guide_audio` / `group_switch` / `vector` / `emotion_map`） |
| `#[情感控制][情绪向量][1,0,0,0,0,0,0,0]` | 最高级覆盖情感。8 维依次为 happy, angry, sad, afraid, disgusted, melancholic, surprised, calm |
| `#[情感控制][文字描述][calm and composed]` | 文字描述情感（走 Qwen 文本情感） |
| `#[情感控制][引导音频][库名/相对路径]` | 用库内音频作情感参考 |
| `#[音色选择][库名/相对路径]` | 最高级覆盖音色（prompt_speech） |
| `#[参数][speed=1.2][diffusion_steps=16]` | 最高级参数覆盖；speed 落标准字段，其余进 kwargs |

优先级：**内联 `#[..]` ＞ 调用方显式 kwargs ＞ 模式默认行为**。未识别的 `#[..][..]` 原样保留；失效引用记 `report.inline_errors` 带原因，不炸请求。

> 控制台「参考音频库」的「复制音色指令 / 复制情感指令」可直接得到上面两种路径格式的内联指令，贴进正文即用。
> 完整语义（与模式/分组的交互、报告字段）见 **`09-控制台与适配层完整参考.md` 第六节**。

## 九、DSH-Tavern 接入（配置一次，长期有效）

```
Provider Endpoint : http://127.0.0.1:9998/v1   ← 控制台适配层（语义见 09 文档）
模型名            : gpt-4o-mini-tts（含 gpt-4o 才触发 DSHT 发情绪指令；适配层路由到本机模型）
API Key           : 本地回环填占位符（如 local）
默认声音/角色音色 : voice = 音色分组名 或「分组名,情绪词」（控制台·音色分组页配置）
情绪              : instructions 情绪指令 / 内联指令（见 09 文档）
```

合成音频按台词 hash 缓存在插件 `speech-cache/`，重复台词不重复合成。

## 十一、排障速查

| 现象 | 处置 |
|---|---|
| `Cluster is not available` | 确认 `--host 127.0.0.1`（勿 0.0.0.0） |
| 就绪超时 | 确认 `XINFERENCE_HEALTH_CHECK_TIMEOUT=180` |
| 401 / 鉴权 | 确认 `XINFERENCE_AUTH_ADVANCED=0` |
| `/health` 404 | 用 `/status`（正常） |
| 合成 500 | kwargs 命令行内联 JSON 被 PowerShell 剥引号 → **写文件 + `-F "kwargs=<文件"`**（见第五节方式四，实测通过） |
| cmd 下 curl 合成失败（000/26/500） | cmd 的 `%` 变量 / `<` 重定向 / 引号拆分三坑 → 用 `-EncodedCommand` 版（见第五节方式四-cmd，实测通过） |
| 下载 `.msc` WinError 183/32 | 权重已下完，重拉跳过；必要时删残留 `.msc` |
| 缺小模型组件 | 手动补齐到 `hf_cache\`（见问题记录 #10） |
| 磁盘满 | 清理；缓存挪 F/G 盘（见 `03`） |

完整排障见 `<部署根>\问题记录\问题记录.md`（73 条）。
