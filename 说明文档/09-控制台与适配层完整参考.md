# 09 - Web 控制台与 OpenAI 适配层完整参考

> 整理：2026-10-25（对应 问题记录 #32–#56 的实现快照）。本文是控制台与适配层的**权威语义文档**；
> 与实现冲突时以 `console/server.py` 为准并回改本文。

---

## 一、总体架构

```
DSH-Tavern / 外部 API 调用方 ──┐
                               ├─→ POST /v1/audio/speech（控制台 9998，标准 OpenAI 端点）
语音合成页·OpenAI 适配模式 ────┘      └─ 适配层：内联指令 → 模式分支 → 分组/标签/映射 → 情感注入
                                            └─ 透传 → Xinference /v1/audio/speech（9997）

语音合成页·直接配置 ─────────→ /api/tts（原样透传 xinference multipart 扩展，无适配）
浏览器管理 ─────────────────→ 控制台静态页 + /api/*（配置/库/分组/映射/历史/缓存/体检）
```

设计原则（用户定调，历次迭代固化）：

1. **适配层是为 API 准备的**——测试台发起的也是标准 API 请求（同端点同行为）；
2. **所有被外部引用的 ID 是绑定唯一键**（库名、分组名；保存时校验重名/空名，抗重排不失效）；
3. **优先级总链：内联指令 > 调用方显式 kwargs > 模式默认行为**。

## 二、控制台（http://127.0.0.1:9998，8 页）

| 页 | 功能要点 |
|---|---|
| 状态总览 | 服务/模型在线状态（/status+/v1/models 合并）、GPU/CPU/内存、缓存与归档统计、一键清空 |
| 语音合成 | 双模式：**直接配置**（IndexTTS-2.5 原生参数，14 项高级参数折叠卡带默认值/建议范围/依据，留空=上游默认）/ **OpenAI 适配**（标准 API 请求字段 + 适配报告 + 最终 kwargs 预览）；两模式各自"存为默认填写" |
| 参考音频库 | 多根库源（页面增删改，`console/library.json`）；搜索过滤；▶ 试听；「用作参考」回填；**「复制名称」**（`库名/相对路径` 完整引用名，clipboard 优先、弹窗兜底） |
| 情绪映射 | 条目编辑器（#50/#52/#54 语义，见 §五） |
| 音色分组 | 分组/成员（标签-音频）编辑；成员 **↑↓ 排序 = 标签匹配优先级** |
| 向量映射 | 触发词→8 维向量表；条目级**启用/停用**复选框（禁用行置灰） |
| API 配置 | 全局默认参数 + **适配默认行为**（五模式下拉，下方动态语义说明）+ 解析开关 |
| 请求历史 | 每次请求（含失败）归档 `console/history/<id>/`（meta.json + 输出音频 + 上传参考副本），试听/删除/清空；缓存命中标记 |

运行时产物（全部 git 忽略、机器专属）：`history/`（500 条上限）、`cache/`（LRU 200 条/1GB，键=参数+参考音频内容哈希，跨客户端稳定）、`console.log`（2MB×3 滚动）、各配置 JSON。

## 三、音频引用格式（唯一定稿）

**外部引用一律用完整名：`库名/相对路径`（正斜杠）**，例：

```
默认音色库/prompt/arknights/zh/临光/clips/zh_临光_001_calm_日常交谈.wav
```

- 库名 = `console/library.json` 里的唯一键（保存时校验重名）；相对路径以正斜杠书写；
- 内联指令 `#[音色选择]`、`#[情感控制][引导音频]` 用此格式；页面「复制名称」一键可得；
- 内部存储：条目存 `root_name`（库名）+ `rel`——**不是位置索引**（#53：索引随库源重排静默失效/指错）；
  旧索引数据保存时自动迁移；解析失败记 `report.broken_refs`（含原因），不静默；
- 「情绪映射」页有**引用体检**按钮（/api/refs/health）：扫全部条目列失效/降级引用。

## 四、适配模式（settings.adapter_mode，五选一）

分组/标签解析通则（各模式一致）：voice 逗号（中英）分段；「分组名 ⊆ 段」命中即**整段消费**
（多段命中取先出现者，段内取最长分组名），首个消费段定分组；剩余段与成员标签做**单向子串**
匹配（标签 ⊆ 词组，整体匹配不分词），**按成员顺序（=标签优先级，音色分组页可调）首个命中**；
未命中用分组默认成员。分组 voice 优先，回退 instructions 中找分组名。

| 模式 | 关键词（model 名子串，中英） | prompt_speech | 情感注入 |
|---|---|---|---|
| 文字情感 text_emotion（默认） | 文字情感 / text_emotion | 标签命中成员（回退默认） | instructions 整段 → emo_text；映射表不参与 |
| 引导音频 guide_audio | 引导音频 / guide_audio | **恒分组默认成员** | 标签命中成员音频 → emo_prompt_speech_b64（音色 A 情绪 B） |
| 切换音色 group_switch | 切换音色 / group_switch | 标签命中成员（回退默认） | **同一成员音频**（与 prompt 保持一致） |
| 情绪向量 vector | 情绪向量 / vector | 标签命中成员（回退默认） | **向量映射**触发词命中 → 配置向量；否则同切换音色 |
| 情绪映射 emotion_map | 情绪映射 / emotion_map | 条目默认成员（音频子条目勾"替换默认音色"时换） | 见 §五 |

**情绪向量模式**：向量映射页规则 = {触发词[], 8 维向量, 启用开关}，子串命中检索文本
（instructions + voice 剩余段），列表顺序首条生效，禁用条目跳过。

**未命中回退链（各模式）**：分组未命中且无上传 → 400（带 report）；有分组但标签未命中 →
默认成员 + 按模式回退（见各模式说明；情绪映射模式见 §五）。

## 五、情绪映射条目（emotion_map 模式核心）

条目结构（`console/emotion_mappings.json`，页面可视化编辑）：

```
条目 = { 绑定音色分组, fallback_text(未命中用文字情感), use_vector_map(未命中用向量映射),
         params_json(条目参数覆盖), items[有序子条目] }
子条目 = 情绪标签-音频 {label 触发词, root_name, rel, replace_default, params_json}
       | 向量映射 {triggers[], vector[8], params_json}
       | 文字情感 {triggers[], text, params_json}
```

执行：分组命中 → 取绑定条目 → 检索文本（instructions + voice 剩余段）按 **items 顺序**子串
命中，首个生效——音频→情绪引导（勾"替换默认"则同时换 prompt_speech）；向量→emo_vector；
文字→emo_text。回退链：子条目未命中 → `use_vector_map` 开 → **向量映射页启用条目等效追加在
子条目之后**处理 → 仍无 → `fallback_text` 开 → 整个 instructions 作 emo_text → 否则无情感注入。

**参数覆盖链**：`#[参数]` 内联 > 子条目 JSON > 条目 JSON > 请求 kwargs（speed 落标准字段；
JSON 解析失败记报告忽略）。

## 六、内联指令（四类，每类首个生效，类型间按序应用）

| 指令 | 语义 |
|---|---|
| `#[适配模式][五种模式名之一]` | 最高级覆盖适配模式（> model 关键词 > settings 默认） |
| `#[情感控制][情绪向量][1,0,0,0,0,0,0,0]` | 最高级覆盖情感；音色选择仍跟随适配模式 |
| `#[情感控制][文字描述][文本]` | 同上（emo_text） |
| `#[情感控制][引导音频][库名/相对路径]` | 同上（第三子类型，与向量/文字同表每类首个竞争） |
| `#[音色选择][库名/相对路径]` | 最高级覆盖 prompt_speech（压过分组/默认成员/上传文件）；音源情感照常跟随模式 |
| `#[参数][k=v][k=v]…` | 最高级参数覆盖（speed 落标准字段，其余按类型归一进 kwargs） |

- 扫描 instructions / voice / input 三字段，命中即剔除；**未识别语法（含 #37 旧五标记）原样保留**；
- 失效（库名/文件不存在等）记 `report.inline_errors` 带原因，不覆盖不炸请求；
- 报告：`report.inline` = {适配模式 / 情感控制 / 音色选择 / 参数}。

## 七、请求契约与端点

标准端点 `POST /v1/audio/speech`（控制台 9998；`/api/tts/adapter` 为别名）：
- **OpenAI JSON 载体**（DSHT 形态）：model / input / voice / instructions / response_format /
  speed [/kwargs dict]；model 值被适配层忽略并路由到本机注册模型（可携带模式关键词）；
- **multipart 载体**（xinference 形态）：上述字段 + kwargs JSON 字符串 + prompt_speech 文件；
- urlencoded（curl -d）亦支持。

DSHT 接入：Provider Endpoint → `http://127.0.0.1:9998/v1`，模型名 `gpt-4o-mini-tts`
（含 gpt-4o 才触发 DSHT 发送情绪指令 instructions），voice 填分组名或「分组名,情绪词」。

直连端点 9997/v1：无适配层，仅 multipart + prompt_speech 可用（DSHT 的 JSON 调用会 400）。

IndexTTS-2.5 能力边界：零样本克隆架构，**无参考音频即拒绝**；不支持文字造声/预设音色
（voice 参数原生不消费）——预设音色由本控制台分组机制补位。情感三路（向量/文字/引导音频）
与参考音频情绪解耦（可用不同人的情绪样本）。

## 八、功能开关与高级参数

- 启动开关（config.ps1）：`USE_QWEN_EMO`（文字情感模型默认不加载、首次请求惰性唤醒）、
  `QWEN_DEVICE`（auto/cpu）；
- 高级参数（合成页折叠卡，留空=上游默认）：扩散步数/CFG/温度/top_p/top_k/num_beams/
  length_penalty/repetition_penalty/max_mel_tokens/分段 token/段间静音/use_random/
  text_normalization/seed——每项带默认值、建议范围与依据（官方仓库 + SECourses 调参指南 +
  本地 config.yaml 硬上限）；
- gpt.pth mmap 加载（内存峰值减半）；自维护包指纹同步（一致跳过，秒级启动）。
