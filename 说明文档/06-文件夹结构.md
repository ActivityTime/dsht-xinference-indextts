# 文件夹结构（Xinference 部署根）

> 更新：2026-10-24（外层整理后）。
> 设计原则：**外层只放启动脚本与 readme**；脚本、数据、文档、日志分区存放；一切可由安装脚本重建/重下的内容一律 git 忽略。

## 一、完整目录树

```
K:\SomeApps\Xinference\                       # 部署根（git 仓库，含 .git）
│
├─ start_xinference_indextts.ps1              # 一键启动：服务 + 加载 IndexTTS-2.5（外层唯一启动脚本）
├─ start_xinference_indextts.bat              # 启动脚本的 .bat 封装
├─ config.ps1                                # 中央配置（启动依赖，须与本层 start 同目录）
├─ README.md                                 # 根说明：环境要求 / 安装 / 使用 / 目录结构
├─ .gitignore                                # git 忽略规则（git 必需，勿移）
│
├─ scripts\                                  # 工具脚本（均无绝对路径：读环境变量 / 相对定位）
│  ├─ install.ps1                            # 安装：venv + xinference + cu128 torch
│  ├─ acl_fix.ps1                            # 应急：修复 System32 MSVC 运行库 ACL
│  ├─ launch_indextts.py                     # 加载 IndexTTS-2.5（读环境变量，无硬编码）
│  ├─ tts_test.py                            # 合成测试客户端（读环境变量，无硬编码）
│
├─ console\                                  # 独立 Web 控制台（自包含；#32/#33，9998）

│  ├─ server.py                              # 后端（代理 9997 + 归档 + 同参数缓存 + 多根音色库 + 日志）
│  ├─ library.json                           # 音色库根配置（多根，页面可编辑；git 忽略）

│  ├─ 02-参考音频库清单.md                     # 声音资产清单（IP × 角色 × 语种 × 段数）
│  ├─ 03-落地与运维手册.md                     # 日常运维速查

│  └─ 官方仓库.txt                            # 官方 git / 文档 / 权重地址
```

## 二、文件归属与 git 跟踪

| 路径 | 类型 | 归属 | git | 说明 |
|---|---|---|---|---|
| `start_xinference_indextts.ps1/.bat` | 启动脚本 | 自写 | ✅ 入库 | 依赖 `config.ps1`（须同目录） |
| `config.ps1` | 配置 | 自写 | ✅ 入库 | 内部路径相对定位、外部引用明文 |
| `README.md` / `.gitignore` | 文档 / git | 自写 | ✅ 入库 | `.gitignore` 是 git 基础设施 |
| `scripts\install.ps1` | 脚本 | 自写 | ✅ 入库 | `$Root` = 上上级（Xinference 根） |
| `scripts\acl_fix.ps1` | 脚本 | 自写 | ✅ 入库 | `$log` 相对 `logs\acl_fix.log` |
| `scripts\launch_indextts.py` | 脚本 | 自写 | ✅ 入库 | 读环境变量，无硬编码 |
| `scripts\tts_test.py` | 脚本 | 自写 | ✅ 入库 | 读环境变量，无硬编码 |
| `logs\` | 日志 | 生成 | ❌ 忽略 | 本机特定，可删 |
| `venv\` | 环境 | 生成 | ❌ 忽略 | install.ps1 重建 |
| `.xinference\` | 模型/数据 | 生成+下载 | ❌ 忽略 | 17.9GB，可重下 |
| `downloads\` | wheel 安装物 | 下载 | ❌ 忽略 | 需要时重建 |
| `说明文档\` / `问题记录\` | 文档 | 自写 | ⚠️ 待 add | 01–06 与架构图尚未 `git add`，建议提交 |

## 三、可重建性（生命周期）

| 内容 | 能否重建 | 重建方式 / 代价 |
|---|---|---|
| 自写脚本与文档（根 + scripts\ + 说明文档\ + 问题记录\） | **不可重建**（唯一资产） | 需 git 备份 / 另存 |
| `venv\` | 可重建 | `install.ps1`（需网络：xinference + cu128 wheel ~2.7GB） |
| `.xinference\` | 可重建 | 重新下载 IndexTTS-2.5 权重（~6GB，HF 镜像） |
| `logs\` | 可删 | 纯日志 |
| `downloads\` | 可删 | 脚本需要时自动重下 |

## 四、移植 / 清理注意

- **整体搬文件夹**：`K:\SomeApps\Xinference` 可直接搬走，脚本无需改（内部路径相对 `config.ps1` 自动适应）；仅需改 User 级 `XINFERENCE_HOME`（可选）+ 目标机具备外部依赖（见 `05-外部引用与配置.md`）。
- **磁盘清理**：优先清 `logs\`（可删）、`venv\`（install 重建）、`.xinference\cache`（重下）。参考音频库 `I:\...\VoiceClonePrompt` **禁止移动**。
- **勿动 `.gitignore`**：它保证 `.xinference`（17.9GB）等不入库，移除会导致 git 误跟踪模型。
- **升级覆盖**：Xinference 升级会覆盖 `worker.py` 的 VRAM 阈值补丁（0.90→0.75），需重打（见 `问题记录\问题记录.md` #14）。
