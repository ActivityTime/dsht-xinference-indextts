# 文件夹结构（Xinference 部署根）

> 更新：2026-10-25（新增中文入口 / 回归测试 / 引用迁移脚本后）。
> 设计原则：**外层只放启动脚本与说明**；脚本、数据、文档、日志分区存放；一切可由安装脚本重建/重下的内容一律 git 忽略。

## 一、完整目录树

```

│
├─ start_xinference_indextts.ps1              # 一键启动：服务 + 加载 IndexTTS-2.5（外层唯一启动脚本）
├─ start_xinference_indextts.bat              # 启动脚本的 .bat 封装
├─ config.ps1                                # 中央配置（启动依赖，须与本层 start 同目录）
├─ README.md                                 # 根说明：环境要求 / 安装 / 使用 / 目录结构
├─ HANDOVER.md                               # 交接总结（现场状态 / 必读顺序 / 关键约定）
├─ .gitignore                                # git 忽略规则（git 必需，勿移）
│
├─ 启动语音服务.cmd                          # 中文入口：起整套（服务+模型+控制台+监控+快捷方式）
├─ 启动监控.cmd                              # 中文入口：只补守护监控（先查 9996，不重复起）
├─ 关闭语音服务.cmd                          # 中文入口：关停全家桶（连根拔起 + 循环杀到零）
├─ 查看监控.cmd                              # 中文入口：桌面状态窗口（红/绿指示灯 + 停止按钮）

├─ status_window.py                          # 桌面状态窗口（Tkinter）
├─ stop_xinference_indextts.ps1              # 关停脚本（连根拔起 + 清孤儿 + 终检）
│
├─ scripts\                                  # 工具脚本（均无绝对路径：读环境变量 / 相对定位）

├─ logs\                                     # 运行 / 安装日志（git 忽略，可安全删除）
```

## 三、可重建性（生命周期）

| 内容 | 能否重建 | 重建方式 / 代价 |
|---|---|---|
| 自写脚本与文档（根 + scripts\ + 说明文档\ + 问题记录\） | **不可重建**（唯一资产） | 需 git 备份 / 另存 |
| `venv\` | 可重建 | `install.ps1`（需网络：xinference + cu128 wheel ~2.7GB） |
| `.xinference\` | 可重建 | 重新下载 IndexTTS-2.5 权重（~6GB，HF 镜像） |
| `logs\` | 可删 | 纯日志 |
| `downloads\` | 可删 | 脚本需要时自动重下 |

## 四、移植 / 清理注意

- **整体搬文件夹**：`<部署根>` 可直接搬走，脚本无需改（内部路径相对 `config.ps1` 自动适应）；仅需改 User 级 `XINFERENCE_HOME`（可选）+ 目标机具备外部依赖（见 `05-外部引用与配置.md`）。
- **磁盘清理**：优先清 `logs\`（可删）、`venv\`（install 重建）、`.xinference\cache`（重下）。参考音频库 `I:\...\VoiceClonePrompt` **禁止移动**。
- **勿动 `.gitignore`**：它保证 `.xinference`（17.9GB）等不入库，移除会导致 git 误跟踪模型。
- **升级覆盖**：Xinference 升级会覆盖 `worker.py` 的 VRAM 阈值补丁（0.90→0.75），需重打（见 `问题记录\问题记录.md` #14）。
