## 一、一键启动（正常情况只做这一件事）

1. 双击桌面快捷方式 `启动Xinference-IndexTTS.lnk`（或直接跑 `start_xinference_indextts.bat`）。
2. 脚本自动：恢复自维护包（指纹一致跳过）→ 起 Xinference 服务 → 等 `/status` 就绪 → bf16 加载 IndexTTS-2.5 → 起控制台（9998）→ 拉起守护监控 → 生成页面快捷方式。
3. 看到 `OK model_uid=IndexTTS-2.5`（服务日志 `ModelActor(IndexTTS-2.5-rep0) loaded`）即就绪。权重已缓存，重拉约 2–3 分钟。

相关文件：
- `start_xinference_indextts.ps1`（主脚本）
- `start_xinference_indextts.bat`（双击入口）
- `G:\Users\ACTIM\OneDrive\Desktop\启动Xinference-IndexTTS.lnk`（桌面快捷方式）

### 中文操作入口（推荐日常用）

项目根目录下四个中文 `.cmd`（纯说明壳，内部复用原脚本，echo 用英文避免任何代码页乱码）：

| 文件 | 作用 | 复用 |

## 一·补 · 控制台运维要点

| 事项 | 要点 |
|---|---|
| **存活感知** | 监控进程（`scripts/monitor_indextts.py`，端口 9996）独立于控制台：控制台死了，状态页与 `STATUS.txt` 仍如实反映。判读：`STATUS.txt` 更新时间停止不动 = 监控也死了。 |
| **禁多实例** | 监控每 20s 按**进程树**收敛：唯一实例 = 监听端口那棵树的全部进程；树外的重复/孤儿**连根拔起**（父子全杀）。模型池（xoscar）在 9997 无监听时全清。**启动时即查重**，不在运行期靠"杀-起"循环。 |
| **单例锁** | 监控用 `msvcrt` 排他锁（`.monitor.lock`）。**stop 脚本不删这个锁文件**——删了等于破锁，会出现双监控竞相重启。 |
| **页面版本号** | 控制台标题带版本号（如 `IndexTTS-2.5 控制台 · 1025-37b3`），一眼确认浏览器加载的是不是最新代码。服务端已对 `/` 下发 `no-store`，浏览器不会再拿旧缓存。 |
| **发布前回归** | 改完代码先跑：`downloads\venv-main\Scripts\python.exe scripts\selftest.py`（18 项：编译/引用格式/内联指令/三端口存活/前端语法/复制逻辑）。 |
| **引用格式** | 🔴 配置框与正文里的库音频引用**一律用库名**，禁止序号（详见 `05-外部引用与配置.md` 第六节）。 |

模型/运行数据收拢在 `<部署根>\.xinference`（cache + huggingface + model + virtualenv + logs + 各 db）。

## 六、常见排障速查（完整记录见 `<部署根>\问题记录\问题记录.md`）

| 现象 | 处置 |
|---|---|
| 服务起不来，`Cluster is not available` | 确认用 `--host 127.0.0.1`（勿用 0.0.0.0） |
| 就绪超时 | 确认 `XINFERENCE_HEALTH_CHECK_TIMEOUT=180` |
| 401 / 鉴权报错 | 确认 `XINFERENCE_AUTH_ADVANCED=0` |
| `/health` 404 | 用 `/status` 探测（正常） |
| 合成 HTTP 500 | 别用 curl 传 kwargs JSON（引号被剥），用 `tts_test.py` |
| 下载 `.msc` WinError 183/32 | 权重已下完，重拉跳过；必要时删 `.xinference\...\.msc` 残留 |
| 缺 semantic_codec/campplus/bigvgan | 手动补齐到 `hf_cache\`（见问题记录 #10） |
| 磁盘满 `no space on device` | 清理；缓存已收拢到 `<部署根>\.xinference`（K 盘剩余需留 ≥25GB） |
| 模型加载失败 `ServerClosed`/`ConnectionResetError` | 大概率是 Xinference VRAM 阈值过严：已本地改 `worker.py` 的 `_VRAM_READY_RATIO` 0.90→0.75（本机豆包/壁纸/Edge 常态占 ~1.5GB）。升级 xinference 会覆盖此补丁，需重打 |
| 想卸模型 / 重启 | 重启启动脚本；重新加载 ~2–3 分钟（权重已缓存） |
