venv\...\torch / torchaudio / torchvision官方2.11.0+cu128 / 2.11.0+cu128 / 0.26.0+cu128（CUDA 12.8 版，官方 PyPI cu128 索引）。

IndexTTS-2.5 权重（HF 缓存）官方IndexTeam/IndexTTS-2.5 全精度约 6GB（hf-mirror.com 镜像下载）。
launch_indextts.py自写RESTfulClient 加载模型，传 model_config={"use_bf16"}（CLI 无此参数），失败自动回退 IndexTTS2。
start_xinference_indextts.ps1自写一键启动：/status 健康探测、最多 4 分钟就绪等待、环境变量、加载模型、打印 DSH-Tavern 接入信息。
start_xinference_indextts.bat自写薄封装：优先 pwsh，否则 powershell 调用 ps1。
acl_fix.ps1 + acl_fix.log自写修复 System32 MSVC/OpenMP 运行库 ACL 损坏（WinError 5 根因：CONCRT140 等 DLL 拒绝读取）。
说明文档\官方仓库.txt自写官方仓库/文档地址备忘（xorbitsai/inference、index-tts/index-tts）。
问题记录\问题记录.md自写8 条排障记录（ACL / cu128 换装 / Cluster not available / 401 鉴权 / /health 404 / CLI 无 bf16 / 精度说明 / 本机环境特殊性）。
根目录 *.log、server.pid自写安装与运行日志（cuda_install*.log、local_install.log、launch.log、server_*.log/err、curl_extra.log）、当前服务 pid。
venv\（环境本身）环境用户创建的 Python 3.13 虚拟环境；内部内容全为官方包。

关键配置（最终可用）

启动命令xinference-local --host 127.0.0.1 --port 9997
监听地址127.0.0.1（勿用 0.0.0.0：内部 health_check 连不上子进程）
就绪超时XINFERENCE_HEALTH_CHECK_TIMEOUT=180（默认 10s 太短，实测 ~51s 就绪）
鉴权XINFERENCE_AUTH_ADVANCED=0（4.x 新增鉴权，本地直连关闭）
HF 镜像HF_ENDPOINT=https://hf-mirror.com
Xet 关闭HF_HUB_DISABLE_XET=1（避免下载卡死）
健康探测/status（4.x 中 /health 返回 404）
模型加载launch_indextts.py（model_config={"use_bf16":true}，CLI 无法传此参数）
DSH-Tavern 接入Provider Endpoint → http://127.0.0.1:9997/v1

项说明
环境变量盘符APPDATA / LOCALAPPDATA / USERPROFILE 均解析到 K:\Users\ACTIM.DESKTOP-BPAEDTM（非 C 盘）。
python 命令第一个解析到豆包沙箱运行时 Python（不可用于正式安装）；真实系统 Python 在 K:\Users\...\AppData\Local\Programs\Python\Python313\python.exe（3.13.16）。
pip 镜像默认华为云镜像 mirrors.huaweicloud.com/repository/pypi/simple/。
